# Claim 1 Algorithm 1 toy

`trace.json` is generated by `src/claim1_algorithm1_toy.py` from the four-feature fixture in the paper appendix. The implementation uses exact `fractions.Fraction` arithmetic for:

1. residual correlation `u = X^T(y-Xk)`;
2. the printed growth-time update and inactive-feature selection; and
3. sign-constrained least squares over the selected and previously active features.

The audit reaches the paper’s selected sequence `[1, 3, 4]`, final vector `(0, 0, 10/7, -10/49)`, and zero squared residual. It records the appendix’s `delta_1=20` printout alongside the formula-derived value `40`; the choice of feature 4 is unchanged.

This is a finite Algorithm 1 audit. It is not a continuous-time gradient-flow or infinitesimal-initialization experiment.
